# workout-demo

Демо-копия тренировок «Женское тело» для показа без подписки: ОДНА тренировка,
первая, «Тренировка 01 · База курса».
Живёт на https://vladlen00.github.io/workout-demo/

Чем отличается от боевого репозитория `workout`:

- гейта нет. Блок `irenaCheckAccess` вырезан целиком, а не закомментирован;
- Supabase нет. Чтение расписания `workout_schedule` убрано вместе с anon-ключом
  и функцией `supabaseFetch`. Единственная тренировка открыта всегда;
- **ни одной ссылки в закрытый телеграм-канал**. Убраны оглавление подкастов,
  `podcastUrl` у тренировки, `selfCheckUrl` и функция `openTgLink`. В боевом
  аппе они и так показывались только в Телеграме, но сами адреса лежали
  в исходнике открытым текстом;
- каталога нет. Шесть остальных тренировок и вкладка «Техники» с шестью
  роликами вакуума выброшены. В файле остаётся РОВНО ОДИН Kinescope ID;
- `telegram-web-app.js` не подключается и не копировался;
- кнопка «← В приложение» заменена на «Что ещё есть» с меткой `?from=demo-workout`;
- `noindex, nofollow` в шапке.

## Правила для этого репозитория

1. Ровно один Kinescope ID и ноль ссылок `t.me`. Проверять при каждой правке.
2. Ни одного обращения к Supabase, ни anon-ключа, ни `workout_schedule`.
3. Демо не читает и не пишет ключи `irena_*`. Здесь хранилище не используется вовсе.
4. Полная проверка перед публикацией, все счётчики обязаны быть нулями:

   grep -c -i -e verify-access -e verify-app-token -e irena_token -e rest/v1 \
        -e workout_schedule -e supabase -e telegram -e t.me -e podcastUrl \
        -e selfCheckUrl -e localStorage index.html

5. Отдельно: ни одна функция не должна остаться вызванной без определения.
   При сборке этот пункт сработал: `openVideo` обращался к `irenaGetInitData`,
   которая уехала вместе с гейтом, и демо падало бы при открытии видео.
   Синтаксис при этом был валидным.
